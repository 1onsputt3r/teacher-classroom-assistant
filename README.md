# 教師課堂助手

可安裝的手機網頁 App。根網址已使用 V2，整合授課班級、有效課表版本、今日八節課表、各班座號名冊、作業、考試、課堂提醒與抽籤；目前仍未連接 Google，也不使用學生姓名。

## 本機預覽

```bash
npm run dev
```

開啟空白的正式本機資料模式：`http://127.0.0.1:4176/`

開啟聯動測試模式（設定頁與今日頁共用同一套假資料）：`http://127.0.0.1:4176/?data-profile=test`

舊的 `/preview-v2/` 網址暫時保留，並與根網址共用同一個來源下的本機資料。

## 測試與建置

```bash
npm test
npm run build
```

完成後的 GitHub Pages 靜態檔案位於 `dist/`。`.github/workflows/deploy-pages.yml` 會在 main 分支更新時先測試、建置，再發布至 `https://1onsputt3r.github.io/teacher-classroom-assistant/`。

PWA manifest 從根網址啟動，因此即使從測試網址安裝，之後由手機主畫面開啟時仍會進入正式資料。Android 的支援瀏覽器可從「設定 → 安裝到主畫面」叫出安裝視窗；iPhone／iPad 需在 Safari 使用「分享 → 加入主畫面」。

## 正式資料、測試資料與備份

- 一般網址一律開啟正式資料，不會自動加入假作業、假考試或假課表；只有 `?data-profile=test` 會進入測試模式。
- 測試畫面會顯示「測試資料｜與正式資料分開儲存」，並使用帶有 `::test::integration-v1` 後綴的獨立本機資料鍵。
- 「設定 → 資料與同步」可匯出或匯入目前模式的完整 JSON 備份；正式備份與測試備份不能互相匯入。
- 測試資料可以清除成空白狀態，重新整理後不會自動復活；按「恢復預設測試資料」才會重新建立整套假資料。
- 本機檔案、`127.0.0.1` 與 GitHub Pages 是不同的網站儲存位置，不會自動共用資料，可用匯出／匯入在它們之間搬移。
- 測試資料含兩個生效課表版本、完整第 1～8 節、週末單日調課、805／806／807 理化及高二甲物理／物理探究。
- 第 1～8 節上下課時間在「課表管理」主頁設定，同一學年度的所有課表版本共用；切換學年度才會使用另一組設定。
- 今日頁可開啟唯讀的完整每週課表，並可切換日期查看當時生效的課表版本；單日調課仍留在各日期的今日頁。
- 各班使用不同最後座號與空號，並包含作業缺交、待補考、當月課堂提醒、手動抽籤加權及本堂抽籤紀錄。
